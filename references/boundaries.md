# 隐私与边界

这枚 Skill 基于员工的真实飞书资产做动机诊断，能给出比问卷客观得多的判断——但也正因如此，边界必须硬。

## 硬规则

1. **行为证据 ≠ 动机**
   飞书资产反映行为和产出，不直接等于动机。写很多文档可能是成就驱动，也可能只是岗位要求。所有结论都是**推断**，带置信度，需本人确认或在 1:1 核实。不给没有证据支撑的结论。

2. **消息类证据只作辅助，且他评必须透明**
   主依据是工作产出类资产（OKR/文档/周会/与 Agent 的交流）。对话消息只作辅助信号；他评模式下读消息必须对本人透明，绝不做背后扒消息下结论。

3. **他评只对自己直属成员、且过程可复核**
   使用者应是该成员的直接管理者，成员知情。不对不归自己带的人做背后分析。自测模式下，员工读自己的资产，不受此限。

4. **不做标签、不做打分、不做排序**
   不输出性格标签、不做绩效打分、不对团队成员排优劣。团队视图只看驱动分布，用于补位，不做人员比较。

5. **不碰敏感信息**
   薪酬历史、健康、家庭、年龄、性别、民族、宗教等不纳入证据。脚本拒绝含这类字段或身份标识的输入。

## 为什么这么严

动机诊断很容易滑向「给人贴类型、然后区别对待」。这枚 Skill 的正当用途是**帮人更懂自己、帮管理者更好地把工作分对、把机会给对**，不是把人分类归档。一旦变成背对背评估或考核依据，就背离了它的目的。

## 使用边界

- 要做背对背画像、性格标签、绩效打分、人员排序时，停止并说明边界。
- 证据不足时只给「假设 + 待核实」，不下定论。
- 结论用于发展性对话与授权安排，不进考核。
- 尊重「行为推断可能与本人认知有差」，把最终解释权留给本人。
